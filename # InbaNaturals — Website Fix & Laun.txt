## Phase 1 — Fix what's actually broken

### 1. Cart button does nothing
- **File:** `src/components/Navbar.tsx`
- **Problem:** The cart icon shows a live item count but has no `onClick`. There's no cart page/drawer anywhere in the app.
- **Fix — pick one:**
  - [ ] **Option A (recommended, less work):** Remove the cart icon/count from the navbar entirely and rely only on the "Order via WhatsApp" button on each product (already working via `getWhatsAppProductLink` in `src/config.ts`).
  - [ ] **Option B:** Build a real cart drawer/page that lists items from `CartContext`, lets you adjust quantity/remove items, and sends the whole cart to WhatsApp as one message.

### 2. Contact form doesn't send anything
- **File:** `src/pages/ContactPage.tsx`
- **Problem:** `handleSubmit` just sets `submitted = true`. No email, no storage, message is lost.
- **Fix:**
  - [ ] Wire it to a form backend — easiest options: [Formspree](https://formspree.io), [EmailJS](https://www.emailjs.com), or [Web3Forms](https://web3forms.com) (all have free tiers, no server needed).
  - [ ] Or write a small serverless function (Vercel/Netlify function) that emails you the submission.
  - [ ] Test that a real submission actually reaches your inbox before calling this done.

## Phase 4 — SEO & discoverability

### 9. No robots.txt or sitemap.xml
- [ ] Add `public/robots.txt` (allow all, point to sitemap).
- [ ] Add `public/sitemap.xml` listing all routes (`/`, `/shop`, `/combos`, `/faq`, `/blog`, `/about`, `/testimonials`, `/contact`, product pages, blog post pages).

### 10. Meta tags are static across every page
- **File:** `index.html`
- **Problem:** One fixed `<title>`/description for the whole site — a shared link to a specific product or blog post shows the same generic title, hurting SEO and link previews.
- **Fix:**
  - [ ] Add `react-helmet-async` (or similar) and set a unique title/description per route, especially `ProductDetailPage.tsx` and `BlogPostDetailPage.tsx`.
  - [ ] Add an `og:image` (currently missing) so shared links show a real preview image.

### 11. No analytics
- [ ] Add Google Analytics 4 and/or Meta Pixel before you start driving traffic or running ads — you want data from day one, not after.

### 12. Structured data (optional but valuable)
- [ ] Add JSON-LD `Product` and `Organization` schema once real content/images are in — helps with Google rich results (price, ratings, etc.).

## Phase 5 — Deployment readiness

### 13. SPA routing needs host configuration
- **Problem:** The app uses `BrowserRouter`, which requires a server-side rewrite rule, or direct links like `/product/hair-oil` will 404 on page refresh.
- **Fix (pick based on host):**
  - [ ] Netlify → add `public/_redirects` with `/* /index.html 200`
  - [ ] Vercel → add `vercel.json` with a rewrite rule to `index.html`
  - [ ] Other static host → check their SPA fallback config

### 14. Housekeeping
- [ ] `package.json` — rename `"name": "sister-sproject"` to something sensible like `"inbanaturals"`.
- [ ] Do a final full click-through of every route on both desktop and mobile before going live.
